# Crop-Parametric-Insurance-

**IrrigaShield** ? Microservices-Based Parametric Crop & Irrigation Insurance Platform built with **Spring Boot 4 (WebFlux / R2DBC / Eureka / API Gateway)**, **Angular 21 (NgRx / Tailwind CSS)**, **MySQL**, and **Playwright E2E Testing**.

## Project Structure
- `Capstone-IrrigaSheild/` ? Backend Spring Boot Microservices (`service-registry`, `api-gateway`, `auth-service`, `farm-service`, `policy-service`, `event-claims-service`)
- `irrigashield-frontend/` ? Angular 21 Single-Page Application with NgRx State Management
- `playwright-testing/` ? End-to-End Automated Playwright Test Suites across all 4 roles (`ADMIN`, `FARMER`, `UNDERWRITER`, `DATA_PROVIDER`)
- `diagrams/` ? System Architecture, Policy Lifecycle, and Claims Lifecycle Diagrams
